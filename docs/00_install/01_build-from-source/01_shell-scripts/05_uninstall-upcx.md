---
content_title: Uninstall UPCX
---

If you have previously built UPCX from source and now wish to install the prebuilt binaries, or to build from source again, it is recommended to run the `upcx_uninstall.sh` script within the `upcx/scripts` folder:

```sh
cd ~/upcx/upcx
./scripts/upcx_uninstall.sh
```

[[info | Uninstall Dependencies]]
| The uninstall script will also prompt the user to uninstall UPCX dependencies. This is recommended if installing prebuilt UPCX binaries or building UPCX for the first time.
