---
content_title: Uninstall UPCXIO
---

If you have previously built UPCXIO from source and now wish to install the prebuilt binaries, or to build from source again, it is recommended to run the `upcxio_uninstall.sh` script within the `upcx/scripts` folder:

```sh
cd ~/upcxio/upcx
./scripts/upcxio_uninstall.sh
```

[[info | Uninstall Dependencies]]
| The uninstall script will also prompt the user to uninstall UPCXIO dependencies. This is recommended if installing prebuilt UPCXIO binaries or building UPCXIO for the first time.
