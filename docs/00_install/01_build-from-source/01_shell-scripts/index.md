[[info | Did you know?]]
| Shell scripts automate the process of building, installing, testing, and uninstalling the UPCXIO software and dependencies.

To build UPCXIO from the source code using shell scripts, visit the sections below:

1. [Download UPCXIO Source](01_download-upcxio-source.md)
2. [Build UPCXIO Binaries](02_build-upcxio-binaries.md)
3. [Install UPCXIO Binaries](03_install-upcxio-binaries.md)
4. [Test UPCXIO Binaries](04_test-upcxio-binaries.md)
5. [Uninstall UPCXIO](05_uninstall-upcxio.md)

[[info | Building UPCXIO is for Advanced Developers]]
| If you are new to UPCXIO, it is recommended that you install the [UPCXIO Prebuilt Binaries](../../00_install-prebuilt-binaries.md) instead of building from source.
