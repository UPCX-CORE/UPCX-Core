There are various ways to install and use the UPCXIO software:

- [Install UPCXIO Prebuilt Binaries](00_install-prebuilt-binaries.md)
- [Build UPCXIO from Source](01_build-from-source/index.md)

[[info]]
| If you are new to UPCXIO, it is recommended that you install the [UPCXIO Prebuilt Binaries](00_install-prebuilt-binaries.md), then proceed to the [Getting Started](https://developers.upcx.io/upcxio-home/docs/) section of the [UPCXIO Developer Portal](https://developers.upcx.io/). If you are an advanced developer, a block producer, or no binaries are available for your platform, you may need to [Build UPCXIO from source](01_build-from-source/index.md) instead.

## Supported Operating Systems

The UPCXIO software supports the following environments for development and/or deployment:

**Linux Distributions**

- Amazon Linux 2
- CentOS Linux 8.x
- CentOS Linux 7.x
- Ubuntu 20.04
- Ubuntu 18.04
- Ubuntu 16.04

**macOS**

- macOS 10.14 (Mojave) or later

[[info | Note]]
| It may be possible to install UPCXIO on other Unix-based operating systems. This is not officially supported, though.
