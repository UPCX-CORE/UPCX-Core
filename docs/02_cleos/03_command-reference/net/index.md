## Description

Interact with local p2p network connections.

## Command

```console
Usage: clupcx net SUBCOMMAND
```

## Subcommands

- [clupcx net connect](connect) start a new connection to a peer

- [clupcx net disconnect](disconnect) close an existing connection

- [clupcx net status](status) status of existing connection

- [clupcx net peers](peers) status of all existing peers
