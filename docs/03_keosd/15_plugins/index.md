## Overview

Plugins extend the core functionality implemented in `kupcxd`. For information on specific plugins, just select from the list below:

- [`http_plugin`](../../01_nodupcx/03_plugins/http_plugin/index.md)
- [`wallet_api_plugin`](wallet_api_plugin/index.md)
- [`wallet_plugin`](wallet_plugin/index.md)

[[info | Kupcxd is modular]]
| Plugins add incremental functionality to `kupcxd`. Unlike runtime plugins, `kupcxd` plugins are built at compile-time.
