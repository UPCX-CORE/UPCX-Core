UPCXIO is the next-generation blockchain platform for creating and deploying smart contracts and distributed applications. UPCXIO comes with a number of programs. The primary ones included in UPCXIO are the following:

- [Nodupcx](01_nodupcx/index.md) (node + upcx = nodupcx) - Core service daemon that runs a node for block production, API endpoints, or local development.
- [Clupcx](02_clupcx/index.md) (cli + upcx = clupcx) - Command line interface to interact with the blockchain (via `nodupcx`) and manage wallets (via `kupcxd`).
- [Kupcxd](03_kupcxd/index.md) (key + upcx = kupcxd) - Component that manages UPCXIO keys in wallets and provides a secure enclave for digital signing.
